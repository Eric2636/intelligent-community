# “我的”页面登录状态失效修复设计

## 问题

“我的”页面只要发现本地存在 `access_token`，用户接口失败后就继续使用全局缓存资料。失效 Token 返回 401 时，缓存手机号仍会让页面显示已登录。

## 设计

- 用户接口成功：以服务端资料更新全局缓存并显示已登录。
- 普通网络错误或 5xx：保留已登录用户的缓存资料，维持离线可用性。
- 401 或 403：视为鉴权失效，清除 Token、手机号授权标记、全局用户资料和未读消息状态，显示授权登录。
- 请求竞态：继续使用现有请求编号和页面存活判断，过期响应不能覆盖新状态。

## 范围

只修改 `pages/my/index.js` 与 `test/my-profile-sync.test.js`，不改变登录弹框、页面样式、接口或其他业务模块。

## 验收

- 401/403 后页面切换为游客状态且本地登录凭据被清除。
- 普通网络失败仍显示已缓存的已登录资料。
- 小程序完整 JavaScript 与 TypeScript 回归测试通过。
