# 小区市场新增权限与统一授权弹框设计

最后更新：2026-07-28

## 背景

小区市场已在新增入口调用统一权限校验，但页面未挂载公共授权登录组件；游客操作只能收到提示，无法进入和其他受限操作一致的授权流程。此前临时改为微信主题的底部弹框，现确认恢复为原有的居中授权卡片。

## 已确认行为

### 小区市场新增入口

- 点击新增商品前调用 `ensureMutationReady(this)`。
- 已登录且已选择身份时进入商品发布页。
- 未登录时只打开统一授权弹框，不进入发布页。
- 授权登录成功后不自动重放新增操作；用户需要再次点击新增按钮。
- 页面卸载后不得继续导航或更新授权状态。

### 统一授权弹框

- 继续使用公共 `auth-login-dialog`，所有已接入页面同步生效。
- 使用 TDesign `t-popup` 居中展示。
- 使用白色紧凑卡片，标题和说明居中展示。
- 按钮纵向排列：上方“授权登录”、下方“取消”。
- 授权按钮使用 TDesign 蓝色，取消按钮使用中性灰色。
- 授权按钮继续使用微信原生 `open-type="getPhoneNumber"`。
- 弹框不可通过点击遮罩关闭，提交期间两个按钮均不可重复触发。
- 保持原有圆角、阴影与按钮高度，避免影响已接入页面。

## 技术边界

- 不复制页面级授权弹框，不新增第二套登录状态。
- 不改变手机号登录、身份选择、取消、错误提示或“登录后再次点击”的业务规则。
- 不修改后台、后端或数据库。
- 不提交、推送、合并或部署。

## 验证

- 自动测试验证小区市场页面挂载公共授权组件、在导航前调用统一权限校验，并在卸载时标记授权页面失活。
- 自动测试验证游客不会进入发布页，登录用户只导航一次。
- 组件结构测试验证居中卡片、纵向按钮、TDesign 蓝色授权按钮和原生手机号授权。
