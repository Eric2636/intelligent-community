# 社区帖子语义标签设计

## 目标

让用户在列表和详情标题旁快速理解留言的优先级和最终业务类型。领域层级以 `docs/小区留言领域模型.md` 为准。

## 标签规则

类型标签互斥显示为 `社区公告` 或 `活动报名`；普通内容帖子不显示类型标签。`置顶` 是独立状态，可显示在类型标签之前。

| 条件 | 标签文案 | 视觉语义 |
| --- | --- | --- |
| `pinned = true` | 置顶 | 橙红色浅底、深色文字，突出优先级 |
| `postType = ANNOUNCEMENT` | 社区公告 | 紫色浅底、深色文字，表示展示栏目 |
| `featureType = REGISTRATION` | 活动报名 | 蓝色浅底、深色文字，表示可报名功能 |

`postType` 表示普通帖子/公告，公告是特殊帖子；`featureType` 的业务名称是“活动类型”，当前为内容/活动报名，未来投票、问卷等扩展仅发生在 `featureType`。公告必须使用 `featureType = CONTENT`，不得成为活动报名帖。

## 覆盖页面

- 我的帖子列表：显示置顶和活动报名标签；公告帖也应显示社区公告标签。
- 社区帖子详情：标题下方/标题右侧以同一顺序显示对应标签。
- 社区列表卡片：复用同一套标签颜色和判断规则，避免各页面颜色含义不一致。

## 单行排列规则

标题与标签使用同一行弹性布局，三个标签放入不可换行的标签组。可用宽度不足时，优先省略标题文本；标签组保持完整，不能拆成两行、截断或溢出卡片。报名人员公开名单不属于本次改动。

## 报名卡片关系

“活动报名”标题标签负责在未进入详情时说明帖子可报名；详情页中的报名卡片继续承担人数、截止时间和报名操作。两者不重复表达报名状态。

## 验收

1. 置顶、社区公告、活动报名的颜色不相同。
2. 标签只在其对应条件成立时展示。
3. 类型标签只能是社区公告或活动报名之一；置顶状态位于类型标签之前。
4. 列表与详情页颜色、文案和顺序一致。
5. 多标签时标签组始终单行完整显示，空间不足时标题省略。
