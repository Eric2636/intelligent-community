# 发布前自测清单

最后更新：2026-07-31

本清单应在合并到 `test` 后，使用体验版和专用测试 API/数据库逐项验证。`dev` 本地验证不等于可以提交审核。

## 一、发布来源与环境

- [ ] 小程序体验版代码来自 `test` 分支，不是 `dev` 或生产分支。
- [ ] API 与后台测试环境也来自 `test` 分支。
- [ ] 上传体验版前，确认本机忽略文件 `config.env.js` 的内容是 `export default 'test';`，实际请求地址为 `https://lllhjh.asia/test-api`。
- [ ] 上传审核版或正式版前，确认 `master` 分支下的 `config.env.js` 内容是 `export default 'production';`，实际请求地址为 `https://lllhjh.asia`。
- [ ] 只有本地开发连接本机后端时才使用 `export default 'local';`；不得以 `local` 配置上传体验版、审核版或正式版。
- [ ] 确认 vConsole 只在 `local` 环境自动开启；`test` 和 `production` 启动时会显式关闭，不显示调试入口。
- [ ] 已理解 `config.env.js` 被 `.gitignore` 忽略，切换或合并 `dev`、`test`、`master` 分支不会自动改变它，因此每次上传前必须人工检查。
- [ ] 对应 API 域名已加入微信公众平台合法域名。
- [ ] 用户隐私保护指引、用户协议和隐私政策已配置且可打开。
- [ ] Mock 已关闭，订阅消息模板 ID 按需配置。

## 二、数据库迁移

- [ ] 已确认连接的是专用开发/测试数据库，并已完成可恢复备份。
- [ ] 已审核 `20260726090000_add_author_avatar_snapshots/migration.sql`。
- [ ] 已审核 `20260726100000_remove_errand_module/migration.sql`。
- [ ] 已审核 `20260726120000_simplify_feedback/migration.sql`。
- [ ] 已审核 `20260726130000_add_notification_center/migration.sql`。
- [ ] 已审核 `20260726160000_add_api_access_logging/migration.sql`。
- [ ] 已审核 `20260731191000_add_avatar_reviews/migration.sql`，确认头像审核表、trace ID 唯一约束及用户/状态/时间索引正确。
- [ ] 在专用环境执行迁移后，任务、帖子/回复、商品/评论/订单的历史用户名和头像已正确回填。
- [ ] 空白头像快照保持可空或归一为 NULL，迁移未把环境相关默认头像 URL 持久化到数据库。
- [ ] 跑腿相关表已删除，任务、论坛、市场、用户和后台功能未受影响。
- [ ] `feedbacks` 表只包含用户、纯文本内容和时间字段及所需索引，不包含类型、联系方式或图片字段。
- [ ] `notifications`、`system_notice_publications`、`Task.version`、`MallOrder.version`、`MallOrder.clientRequestId` 和 `(buyerId, clientRequestId)` 复合唯一约束已创建并可用。
- [ ] `api_endpoints`、`api_access_logs`、`api_error_logs` 已创建，接口唯一约束、默认开关和按时间/IP/接口/状态等筛选索引可用。

注意：仓库中存在迁移文件不代表迁移已经执行。没有明确数据库目标、备份和回滚准备时不得运行迁移。

## 三、授权登录

- [ ] 游客进入公开页面不会被强制跳转到“我的”。
- [ ] 游客点击发布、领取、评论、收藏、下单或私有列表时，当前页弹出“授权登录/取消”。
- [ ] 点击取消后保持游客状态和当前页面，不执行原操作。
- [ ] 拒绝手机号授权后不产生业务写入。
- [ ] 首次授权成功后可以选择“业主”或“小区外人员”身份。
- [ ] 授权和身份选择完成后不自动执行原操作；再次点击同一按钮才执行。
- [ ] 快速连续点击授权入口不会发起重复登录或重复身份选择。

## 四、资料、头像与历史内容

- [ ] 任务、论坛、市场等内容模块中，API serializer 的 `avatarOrDefault` 对 NULL/空白头像返回可展示值，小程序 `defaultAvatar` 再次兜底；“我的”页头像为空或加载失败时使用 TDesign `t-avatar` 的用户图标/组件兜底，均不出现空白或破图。
- [ ] 修改用户名后，既有任务、帖子/回复、商品/评论和订单相关展示同步更新。
- [ ] API 生产环境已配置 `WX_MESSAGE_TOKEN`；微信公众平台消息推送 URL 为 `https://lllhjh.asia/api/wechat/content-security/callback`，Token 完全一致，消息加密方式为明文模式，数据格式为 JSON，GET 校验成功。
- [ ] 使用“微信头像”入口上传后不立即替换旧头像，页面显示“头像审核中，通过后自动生效”；微信返回 `pass` 后自动刷新，并同步更新上述历史内容。
- [ ] 使用“自定义”入口重复同一流程，确认也调用内容安全审核，不存在直接保存头像的旁路。
- [ ] 微信返回 `risky` 或 `review` 时旧头像保持不变，只显示通用未通过提示，不向用户暴露分类 label；微信接口/回调失败时旧头像也保持不变。
- [ ] 连续快速上传两张头像时，只有最新一张通过后可以生效；较早请求的迟到回调不能覆盖最新头像。
- [ ] 审核中退出并重新进入资料页后会恢复查询；离开页面后停止轮询，不继续更新已卸载页面。
- [ ] 普通资料 PATCH 与微信登录携带的 `avatar`/`avatarUrl` 均不能绕过审核直接修改头像。
- [ ] 资料更新和快照同步失败时整笔事务回滚，不出现用户资料已更新但历史内容未更新的半成品状态。

## 五、任务中心

- [ ] 任务列表、详情、发布、领取、提交完成、确认完成和取消流程正常。
- [ ] “我的任务”可切换“我发布的/我领取的”，Tab 切换不新增页面栈。
- [ ] 多次切换 Tab 后按一次返回，直接回到“我的”页。
- [ ] 快速切换 Tab 时，较早返回的请求不会覆盖当前 Tab 内容。
- [ ] 离开“我的任务”页面后，迟到请求不会继续更新已卸载页面。

## 六、业主互助

- [ ] 帖子列表和详情展示作者用户名与头像。
- [ ] 发帖、回复、点赞、收藏、删除等受保护操作遵循统一授权弹框和“登录后再点一次”规则。
- [ ] 我的帖子、我的收藏和详情互动正常。

## 七、小区市场

- [ ] 清空登录态后可查询分类、已上架商品列表、已上架商品详情和评论。
- [ ] 游客查询不会访问或返回个人收藏、点赞数据，个性化字段为安全默认值。
- [ ] 携带有效登录态后，公开查询正确返回当前用户的收藏/点赞状态。
- [ ] 过期或无效 token 访问公开查询时按游客继续，不因 401 阻断浏览。
- [ ] 游客不能查看他人的下架或已删除商品及其评论；发布者登录后可查看自己的下架商品。
- [ ] 发布、评论、收藏、下单、我的商品、我的收藏和我的订单仍要求登录。

## 八、跑腿下线

- [ ] 首页、底部导航、“我的”、模块配置中不存在跑腿入口。
- [ ] 小程序包中不存在 `pages/errand` 和 `packageErrand` 页面。
- [ ] API 不再注册 `/api/errands` 路由，上传模块不再接受 `errand` 类型。
- [ ] 后台菜单、类型和内容管理中不存在跑腿。
- [ ] 打开旧跑腿收藏/分享深链时提示“功能已下线”，只回到任务首页一次，不白屏、不循环跳转。

## 九、第二阶段搜索、列表与反馈

- [ ] 小程序任务、论坛和市场输入搜索词后，停止输入满 500ms 才查询；连续输入期间不查询。
- [ ] 搜索词会先 trim；相同有效关键词重复输入不重复查询，页面不存在额外搜索按钮。
- [ ] 输入全空白时不携带关键词查询并恢复默认列表；已处于默认状态时重复空白不额外查询。
- [ ] 快速切换关键词时，旧请求的成功、失败和 finally 都不会覆盖最新列表、加载态或错误提示。
- [ ] 在微信开发者工具执行“工具 → 构建 npm”，确认 `rxjs` 可从 `miniprogram_npm` 正常解析，并检查构建后包体符合微信限制。
- [ ] 在 320px、375px、430px 三档模拟器或真机逐一检查 10 个列表：标题最多 1 行，正文/摘要最多 3 行，超出省略且不被头像、金额、状态或时间挤出屏幕。
- [ ] “更多服务”只显示消息通知和意见反馈。
- [ ] 意见反馈页只有内容输入框和提交按钮，前后端均按 trim 后 1–500 个 Unicode code points 校验，不存在反馈图片、类型或联系方式入口/字段。
- [ ] 游客首次点击提交只弹授权登录；授权完成不自动提交，再次点击才保存一条反馈。
- [ ] 后台 5 个列表仍由显式查询触发，不做热搜索；普通 Enter 与搜索按钮行为一致并先回到第 1 页。
- [ ] 后台登录支持普通 Enter；中文输入法组合态、keyCode 229 和长按重复键不会误触发查询或登录。
- [ ] 后台连续查询时只接受最新请求结果，较早返回的请求不能覆盖当前页面。

## 十、第三阶段消息通知

- [ ] 论坛帖子被他人直接回复生成 `FORUM_POST_REPLY`；评论被他人回复生成 `FORUM_REPLY_REPLY`；回复自己不生成通知。
- [ ] 任务领取、放弃、提交完成、确认、驳回和发布者取消分别通知正确的另一方；同一状态版本重试不重复生成。
- [ ] 市场下单通知卖家，买卖任一方取消通知另一方，卖家完成通知买家；重复下单意图和状态重试不重复生成。
- [ ] 点赞和收藏均不生成通知。
- [ ] “我的”和自定义底栏未读数来自服务端；点击、全部已读和删除后同步刷新，重复操作不出现负数。
- [ ] 业务通知点击后进入对应帖子、任务或订单；目标已删除、无权限或不存在时提示“内容已不存在”。
- [ ] 系统通知直接在列表内阅读；只有超级管理员能看到后台入口、访问页面和调用发布接口。
- [ ] 通知列表左滑显示红色“删除”，删除仅软删除当前用户的通知；删除他人通知编号或重复删除返回 404。
- [ ] 在真机验证仿 iOS/微信列表左滑手势、按钮点击区域和滚动不冲突。

## 十一、第四阶段接口访问日志与接口管理

以下项目必须在第四阶段代码完整后执行；当前模型、中间件和接口注册服务存在不代表本节已通过。

- [ ] 小程序和后台的 GET/POST、成功、400/401/403、500、上传及不存在的 404 请求均进入统一采集流程，标准路由不会按实际动态编号重复注册。
- [ ] 新接口首次注册时普通日志默认开启；重启同步不会覆盖管理员已保存的描述或日志开关。
- [ ] 普通日志记录来源、方法、标准路由、脱敏实际路径、可信 IP、用户/管理员编号、HTTP/业务状态、耗时和调用时间，不保存完整请求头、请求体、Cookie、Token、微信凭证或上传文件内容。
- [ ] 关闭某接口普通日志后，200/400 不再写普通访问日志；同一接口发生 500 时仍写独立错误日志，重新开启后普通日志恢复。
- [ ] 日志数据库写入失败时，原业务状态码和响应体不变，服务端留下明确的日志持久化故障告警。
- [ ] 仅超级管理员能看到并访问接口管理、访问日志和错误日志；普通管理员的菜单、深链和 API 均被拒绝。
- [ ] 接口管理可修改描述和日志开关，变更前后值、操作者和时间写入管理员操作日志；开关修改失败时后台恢复原值。
- [ ] 同一 PATCH 同时修改描述和日志开关时，分别产生 `API_ENDPOINT_DESCRIPTION_UPDATE` 和 `API_ENDPOINT_LOGGING_UPDATE` 两类操作记录。
- [ ] 访问日志支持按 IP、接口、方法、来源、精确状态码/状态类别、时间范围、用户/管理员和耗时筛选，默认时间倒序分页；Enter 查询、重置和翻页行为正确。
- [ ] CSV 导出与当前筛选条件完全一致，最多 50,000 行，编号可安全 JSON/CSV 序列化，不包含错误堆栈、Token、请求体或未脱敏敏感信息。
- [ ] 错误日志默认查看 5xx，详情只展示脱敏错误摘要、路由、状态和耗时，不展示完整堆栈、请求头或请求体。
- [ ] 只有部署在明确受控的可信反向代理后才启用 `TRUST_PROXY=true`，并配置 `TRUST_PROXY_IPS`；只有 socket peer 命中白名单才读取转发头，非可信来源伪造转发头时仍记录 socket IP。
- [ ] 在专用测试数据库插入 89/90/91 天样本并执行清理；只删除严格超过 90 天的访问/错误日志，每批不超过 5,000 行，接口配置和管理员操作日志不受影响。
- [ ] 分别对日志开启/关闭执行同组请求并记录 P50/P95；日志功能没有不可接受的业务延迟，进程退出和故障场景不会静默丢失必须保留的 5xx。
- [ ] 后端完整测试、lint、build 与后台接口日志页面测试、build 均退出码为 0；OpenAPI、字段说明、后台说明和功能状态与最终实现一致。
