## 二、隐私、协议与授权登录（小程序内）

- [ ] 小程序没有独立登录页，游客可浏览公开内容
- [ ] 点击 **《用户协议》** 能打开协议页并看到完整内容
- [ ] 点击 **《隐私政策》** 能打开隐私政策页并看到完整内容
- [ ] 未登录时触发发布、领取、评论、收藏等完整功能 → 直接发起微信授权登录
- [ ] 拒绝授权 → 继续保持游客浏览状态
- [ ] 首次授权成功后 → 选择「业主」或「小区外人员」

详见 **《隐私与协议验证说明》**。
