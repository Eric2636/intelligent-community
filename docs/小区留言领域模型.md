# 小区留言领域模型

## 领域语义

公告是一种特殊帖子。每篇帖子同时具有帖子类型、活动类型和独立的置顶状态：

```text
帖子
├── postType：NORMAL（普通帖子）/ ANNOUNCEMENT（公告）
├── featureType（活动类型）：CONTENT / REGISTRATION / 未来扩展
└── pinned：独立置顶状态
```

- **公告**：`postType = ANNOUNCEMENT` 的特殊帖子，必须使用 `featureType = CONTENT`。
- **内容**：当前的默认活动类型。
- **活动报名**：带人数上限、截止时间和报名名单的活动类型，仅任意有效管理员可以发起。
- **未来扩展**：投票、问卷等能力只扩展 `featureType`。

## 字段映射

| 业务含义 | `postType` | `featureType` |
| --- | --- | --- |
| 公告 | `ANNOUNCEMENT` | `CONTENT` |
| 内容帖子 | `NORMAL` | `CONTENT` |
| 活动报名帖 | `NORMAL` | `REGISTRATION` |

约束：

1. `postType = ANNOUNCEMENT` 时，`featureType` 必须为 `CONTENT`；公告不得使用 `REGISTRATION`。
2. `postType` 表示普通帖子或公告；`featureType` 表示活动类型，当前为内容或活动报名。
3. `pinned` 是独立状态，不属于活动类型。
4. 后台保留标题前的现有“公告”标签，只新增“活动类型”列；不新增“公告/帖子”或“留言类别”列。

## 权限

- 内容帖：普通用户和有效管理员均可按现有规则发布。
- 公告、活动报名、置顶和附件：仅有效管理员可操作，后端必须拒绝普通用户伪造请求。
- “有效管理员”指能正常登录后台管理系统且未被禁用的管理员。
- 后台发布的帖子明确记录后台创建者；普通管理员仅能管理和查看自己创建帖子的报名名单，超级管理员可查看全部。

## 命名要求

- `postType` 称为“帖子类型”，表示普通帖子/公告。
- `featureType` 的后台业务名称统一为“活动类型”。
- 不得把公告、内容、活动报名当作三个同级类型；未来扩展只发生在 `featureType`。
