# 管理后台说明

最后更新：2026-07-28

管理后台由两个与小程序仓库同级的独立项目组成：

- `../intelligent-community-admin`：Koa + TypeScript + Prisma API 服务。
- `../intelligent-community-admin-web`：后台管理 Web。

当前项目不再采用“复制 admin 云函数到小程序并上传”的旧流程。API 服务、后台 Web 和小程序应分别按各自分支及目标环境构建验证。

## 当前第一至第三阶段变更

- 用户资料更新会同步任务、论坛和小区市场中的历史用户名与头像展示快照。
- 数据库头像快照允许为 NULL；API serializer 使用 `avatarOrDefault`，小程序显示层使用 `defaultAvatar` 再次兜底，界面不会出现空白头像。
- 小区市场分类、在线商品列表、在线商品详情和在线商品评论允许游客查询；登录后返回当前用户个性化状态。
- 小区跑腿已从小程序、API、后台菜单/类型和接口文档下线。
- 当前五份数据库迁移已经生成，但尚未在专用开发/测试数据库执行：
  - `20260726090000_add_author_avatar_snapshots`：新增并回填历史用户名/头像展示快照。
  - `20260726100000_remove_errand_module`：删除跑腿相关表。
  - `20260726120000_simplify_feedback`：新增只保存用户、纯文本内容和时间的反馈表及索引。
  - `20260726130000_add_notification_center`：新增 `notifications`、`system_notice_publications`，为任务和市场订单增加 `version`，并为订单增加 `(buyerId, clientRequestId)` 复合唯一约束。
  - `20260726160000_add_api_access_logging`：新增接口注册表、普通访问日志表、5xx 错误日志表和常用筛选索引。
- 意见反馈接口要求登录，只接受 trim 后 1–500 个 Unicode code points 的 `content`，不接受类型、联系方式或图片。
- 后台 5 个列表查询和登录支持普通 Enter；后台搜索不是热搜索，并使用 latest-wins 防止旧请求覆盖最新结果。
- 用户通知 API 已提供分页、未读数、单条/全部已读和按当前用户软删除。
- 后台新增“系统通知”入口，仅超级管理员可见、可访问和发布；普通管理员深链访问也会被前后端拒绝。发布使用 `clientRequestId` 保证安全重试，并写入管理员操作日志。
- 全接口日志和接口管理仍属于第四阶段，当前旧日志页面不等于第四阶段已经完成。

## 第四阶段接口日志（实现中）

当前后端 `dev` 工作区已有：

- `ApiEndpoint`、`ApiAccessLog`、`ApiErrorLog` 三个模型和 `20260726160000_add_api_access_logging` 迁移；
- 从 Koa Router 自动同步“请求方式 + 标准路由”的接口注册服务，新接口默认开启普通日志；
- 最外层访问日志中间件、基础路径/错误摘要脱敏、日志写入故障隔离，以及关闭普通日志时仍记录 5xx 的基础实现。
- 仅超级管理员可用的接口管理、访问日志/错误日志查询、筛选和 CSV 导出 API；
- 后台接口管理、访问日志、错误日志页面及菜单/路由守卫；
- 描述/开关变更分别写入管理员操作日志的行为与测试、OpenAPI 声明和 90 天分批清理脚本。
- 90 天边界/5,000 行批次行为测试，以及 `TRUST_PROXY_IPS` 可信 socket peer 白名单限制。

以下能力仍待完成或验收：

- 将清理脚本接入目标环境低峰期定时任务并核对运维输出；
- 目标环境代理白名单配置、全部筛选条件、脱敏、故障隔离、500 兜底、性能和全量自动测试验收。

完整字段、安全边界和待办见 `../../intelligent-community-admin/docs/接口访问日志说明.md`。现有“小程序接口错误日志”是客户端上报错误的旧功能，不能代替第四阶段服务端全接口访问日志。

## 分支与发布规则

- 代码和文档只在 `dev` 修改。
- 测试环境只从 `test` 发布。
- 生产环境只从生产分支发布。
- 本地构建和测试不授权提交、推送、合并或部署。

## 数据库注意事项

执行当前迁移前必须确认数据库目标、完成备份并准备回滚方案。先在专用开发/测试数据库验证：

1. 历史展示快照的字段和索引创建成功。
2. 论坛主帖等历史用户名与头像快照回填正确；空白头像归一为 NULL，数据库不持久化环境相关默认 URL。
3. 跑腿表删除后，任务、论坛、市场、用户和后台查询均正常。
4. `feedbacks` 表只包含当前纯文本反馈所需字段和索引。
5. `notifications` 的接收人/去重唯一键、未读与软删除索引正确，`Task.version`、`MallOrder.version` 和订单幂等复合唯一键生效。
6. `api_endpoints`、`api_access_logs`、`api_error_logs` 及其唯一约束、默认开关和常用筛选索引正确；迁移完成不等于第四阶段整体验收已通过。

迁移文件存在不代表目标数据库已经变更。禁止在数据库环境不明确时执行迁移。

API 本地开发、接口语义和迁移文件说明见 `../../intelligent-community-admin/README.md`；具体接口以 API 服务启动后的 `/api-docs` 为准。
